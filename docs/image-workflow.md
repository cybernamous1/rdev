# Image asset workflow

- Prefer WebP for raster images where practical.
- Resize to the rendered dimensions and create responsive variants when useful.
- Lazy-load below-the-fold images and reserve layout space with dimensions/aspect ratio.
- Preserve code and UI screenshot legibility; quality targets are guidance, not hard limits.
- Keep original files where required for attribution, license compliance, or future editing.
- Record source, creator, license, and permitted reuse conditions.
- Keep logos and icons as optimized SVG where appropriate.
