## 3. Database

Additive only; all `IF NOT EXISTS`; no existing table altered, dropped, truncated or rewritten. Six new tables, each necessary: `discovery_jobs`, `discovery_frontier` (resumable crawl state; `discovery_runs` cannot represent unfinished runs), `host_policies` (robots cache/politeness), `discovered_source_meta` (one row per existing candidate; `discovered_sources.category` has a CHECK that cannot be widened without recreating the table), `license_evidence` and `license_reviews` (append-only, with safeguard triggers). Instructions: `database/README.md` ("Upgrading v0.4.0 -> v0.5.0").

Verified locally (`tests/engine-db.test.ts`, SQLite via `node:sqlite`): upgrade of a v0.4.0 copy (legacy 0.3.0 schema + `upgrade-0.4.0.sql` + seeded data) leaves every pre-existing table/row byte-identical and adds exactly the six tables; rerunning changes nothing; a non-0.4.0 database is refused before anything is created; `init.sql` and the upgrade path produce identical schemas and an identical v0.5.0 block; `delete.sql` removes everything; foreign-key check clean; v0.4.0 triggers still hold; licensing triggers behave. **Not verified: execution on Cloudflare D1** (statement-by-statement execution of the migration, D1 batch atomicity of `wrangler d1 execute --file`, and JSON1 function availability in D1 are assumed from SQLite behaviour).

## 4. Additional programming languages

**None are introduced, deliberately.** No Rust/Go/C/C++/Kotlin toolchain was available, and nothing showed TypeScript to be too slow for these workloads (HTML/XML parsing of at most 1.5 MB per page, SimHash of at most 3,000 words), so adding a language would be experimentation, which the brief forbids. What exists instead: the runtime capability registry (verified modules only; TypeScript wins ties; per-module timeout, failure isolation, circuit breaker and fallback), a WebAssembly adapter for the `rdev-module/1` contract (no imports, fresh instance per call, pointer/length validation), and a manifest verifier that rejects any module lacking its own dependency manifest + lockfile, build config, reproducible build instructions, entry point, interface, benchmark-backed advantage and a **workerd/wrangler** compatibility report (a Node-only check is rejected for non-TypeScript modules). The adapter is tested with a hand-assembled WebAssembly echo module (a test fixture, not shipped). Built-in TypeScript modules are labelled `verified-local` (static Workers-API scan + Node tests), **not** `verified-workers`. Downloaded or discovered code is never executed (also asserted by test).

## 7. Known limitations and unresolved issues

* Baseline incomplete (section 0); existing suites unrun; nothing verified on Cloudflare (Workers CPU/subrequest limits, D1, `DecompressionStream` and `fetch` behaviour in workerd, GitHub API rate limits). The default step budget (10 pages plus robots fetches) is a conservative guess.
* Heuristics are keyword/structure rules; real-world false positives/negatives are expected, especially for language detection on short pages, directory detection, and licence wording. Pages requiring JavaScript, PDFs and video are not read. No public-suffix list: "same site" is host equality (minus `www.`).
* Candidate `category` for third-party pages is stored as `official-docs` (schema constraint); the true type is in `discovered_source_meta`.
* Licensing clearance is **recorded and displayed but not enforced** as a publication gate (it would change v0.4.0 behaviour for existing content). The existing v0.4.0 "license text recorded on the source" gate still applies. Recommend deciding whether to add a gate.
* `api.github.com` is exempt from robots.txt (documented API); unauthenticated limit is low, so repository discovery defers after 403/429.
* Owner Console UI was type-checked with stand-in React types and **never rendered in a browser**.
* Re-check (`/recheck`) updates monitoring state only; it does not re-extract or touch proposals. There is no scheduler by design.
* Terms/legal pages are only fully read when the owner runs the licence scan (it reads at most two linked pages); other terms links are flagged as unread.
